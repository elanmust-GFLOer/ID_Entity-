# ID_Entity 🧬

Offline kutatási alap az ember–MI együttműködés identitás-, felhatalmazás- és bizonyítékmodelljéhez.

Az első v0.1 scaffold külön draft pull requestben készül felülvizsgálatra. A GFLO v0.2 biztonságos pilot-előkészítése elsőbbséget élvez.

Ez a repository jelenleg nem hitelesítő szolgáltatás és nem ad éles agent-, wallet- vagy GFLO XP-jogosultságot.
